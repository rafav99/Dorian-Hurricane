# Input frames

This directory contains the 35 consecutive RGB frames used by the analysis (`Frame_1.png` to `Frame_35.png`). The project treats consecutive frames as separated by 10 minutes and uses the 1 km/pixel scale specified for the original exercise.

The imagery carries a NASA Worldview watermark. It is included here only to make the analysis reproducible; no ownership or licensing claim is made over the source imagery.
